# CRBEinternship

Main scripts for the internship at CRBE

## Organisation/subprojects

- **ONITS** : A pipeline for fungal (but not only) metabarcoding on Oxford Nanopore Technologies based on [PRONAME](https://github.com/benn888/PRONAME)
- **Pipeline comparison** : R stats to compare metabarcoding pipelines
- **TAXINFO usages** : R scripts to use taxinfo on a the cluster and mutltiple usage examples

Each sub parts has its own README and wiki for more details over usage and examples
